# Fractions — Misconception Taxonomy

| Code | Category | Operational description | Example evidence | Follow-up probe |
|---|---|---|---|---|
| M01 | Additive numerator/denominator error | Adds numerators and denominators directly | 1/2 + 1/3 = 2/5 | Draw both fractions; how many equal-sized parts are in the whole? |
| M02 | Whole-number bias in comparison | Treats larger denominator as a larger fraction | Says 1/8 > 1/4 because 8 > 4 | Which is larger: one slice out of 4 equal slices or 1 out of 8? Explain. |
| M03 | Common-denominator difficulty | Does not create equivalent fractions before adding/comparing | Adds 1/2 + 1/3 without conversion | Rewrite both fractions with denominator 6. |
| M04 | Equivalence misconception | Does not recognize fractions with the same value | Claims 1/2 and 2/4 are unequal | Show 1/2 and 2/4 on the same number line. |
| M05 | Procedural/arithmetic slip | Conceptual method is sound but arithmetic is incorrect | Correctly converts to sixths but sums incorrectly | Repeat the arithmetic while keeping the fraction method. |
| M06 | Insufficient evidence / uncertain | Response does not reveal a stable reasoning pattern | Blank, guess, contradictory or unexplained answer | Ask learner to explain or represent the answer visually. |

## Labeling rules
- Store one primary label plus optional secondary labels.
- `Correct` is an outcome, not a misconception code.
- Do not assign M01–M05 solely from a wrong final answer when the explanation is absent.
- Use M06 when evidence is insufficient or contradictory.
- Keep the original response and evidence alongside every label.
- Confidence is a calibrated estimate, not a claim of certainty.

## Suggested confidence bands
- 0.80–1.00: strong evidence; still teacher-reviewable.
- 0.50–0.79: tentative; ask a diagnostic probe or request teacher review.
- 0.00–0.49: insufficient evidence; use M06 and gather more information.

These bands are initial engineering defaults and should be validated against teacher-labelled examples.

## Mathematics — Basic algebra

| Code | Category | Operational description |
|---|---|---|
| ALG01 | Inverse-operation confusion | Applies an operation to one side of an equation without preserving equality. |
| ALG02 | Distribution error | Multiplies only one term inside parentheses instead of every term. |
| ALG03 | Variable operation confusion | Treats the variable as a label or reverses the operation used on it. |

## Science — Force and motion

| Code | Category | Operational description |
|---|---|---|
| FM01 | Motion requires continuing force | Believes an object must keep experiencing a forward force to maintain motion. |
| FM02 | Speed relationship confusion | Does not relate average speed to distance divided by elapsed time. |
| FM03 | Force and acceleration confusion | Confuses net force, mass, and acceleration in Newton's second law. |

## Science — Basic electricity

| Code | Category | Operational description |
|---|---|---|
| EL01 | Open-circuit misconception | Does not recognize that a simple circuit needs a complete conducting path. |
| EL02 | Current-used-up misconception | Believes current is used up as it passes through components in series. |
| EL03 | Current and voltage confusion | Treats current and voltage as interchangeable quantities. |

## English — Grammar

| Code | Category | Operational description |
|---|---|---|
| GR01 | Tense consistency error | Does not use verb tense consistently with the stated time. |
| GR02 | Pronoun-antecedent agreement | Chooses a pronoun that does not agree with or clearly refer to its antecedent. |
| GR03 | Sentence conventions | Misses capitalization or terminal punctuation needed for a complete sentence. |

## English — Subject-verb agreement

| Code | Category | Operational description |
|---|---|---|
| SV01 | Intervening-noun distraction | Matches the verb to a nearby noun instead of the sentence's subject. |
| SV02 | Singular/plural agreement | Does not match the verb form to a singular or plural subject. |
| SV03 | Compound-subject agreement | Treats a compound subject joined by 'and' as singular. |

`FOLLOW_UP` is used when evidence is insufficient outside fractions; it is not
a subject misconception code. The legacy fractions code `M06` remains in use
for the same follow-up-only state.
